# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Overview

This laboratory examined the basic resources that make up a cloud infrastructure environment. A Linux server was inspected through KillerCoda to identify its system, compute, memory, storage, and network characteristics. The activity also involved comparing services from three major cloud providers and creating a basic cloud architecture design.

## Objectives

- Identify important Linux server resources.
- Explain the role of compute, storage, networking, and operating systems.
- Compare equivalent services from AWS, Azure, and Google Cloud.
- Design a simple cloud infrastructure architecture.
- Practice documenting technical findings.
- Manage laboratory files using Git and GitHub.

## Environment

The investigation was performed using the KillerCoda Linux environment. The server runs Ubuntu 24.04.4 LTS and uses a Linux kernel. The environment provides virtual CPU, memory, storage, and networking resources.

## Main Findings

The server has one CPU core and approximately 1.9 GiB of RAM. Its primary filesystem is /dev/vda1 with 19 GB of storage. The main network interface is enp1s0 with the IPv4 address 172.30.1.2/24.
