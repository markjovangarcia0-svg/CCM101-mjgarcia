# Cloud Provider Comparison

## Service Comparison

| Category | Amazon Web Services | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Google Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| IAM | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS provides a very large selection of cloud services. It supports common infrastructure services as well as databases, analytics, security, application development, and other specialized workloads. Because of this variety, AWS is a strong option for organizations that want many services available from one provider.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Azure would be a practical choice for an organization that already depends heavily on Microsoft technologies. Its services are designed to work with Microsoft's identity, server, productivity, and development ecosystem, which can make integration and administration easier.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

Google Cloud is well known for its capabilities in artificial intelligence and machine learning. It also provides Google Kubernetes Engine for managed Kubernetes deployments, making it a strong platform for containerized applications.

### 4. What similarities did you observe among the three cloud providers?

The three providers offer comparable fundamental services. Each has virtual computing resources, cloud storage, virtual networking, and identity and access management. They also provide scalable infrastructure and security controls for cloud workloads.

## Conclusion

Although the service names differ between AWS, Azure, and Google Cloud, the basic infrastructure concepts remain similar. Learning the purpose of each component makes it easier to understand equivalent services across different cloud platforms.
