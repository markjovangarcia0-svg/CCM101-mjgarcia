# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I consider networking to be especially important because cloud resources need a way to communicate. Even if a server has enough CPU, memory, and storage, users cannot properly access the application if the network is not configured correctly. Networking connects users with applications and also allows different cloud resources to exchange information.

## 2. How does Linux support cloud computing?

Linux provides a practical environment for operating cloud servers and virtual machines. Its command-line tools make it possible to inspect hardware resources, storage, network interfaces, processes, and system configuration. During this activity, Linux commands helped me understand what resources were available inside the KillerCoda environment.

## 3. Why is technical documentation important before deploying infrastructure?

Documentation gives engineers a clear record of what has been investigated or designed. It can show the available resources, explain how components are connected, and provide information that can be used when troubleshooting. It also helps other team members understand the infrastructure without having to repeat the entire investigation.

## 4. What new skills did you learn during this laboratory activity?

I learned how to interpret Linux system information and relate it to cloud infrastructure concepts. I also practiced identifying network interfaces and storage filesystems. Another skill I developed was comparing equivalent services between AWS, Azure, and Google Cloud instead of looking at each platform as a completely separate system.

## 5. How has your GitHub portfolio improved after completing this mission?

The portfolio now contains a more detailed record of my cloud infrastructure work. Instead of only keeping command results, I organized the information into technical reports, component explanations, provider comparisons, screenshots, and an architecture diagram. This makes the repository easier to review and shows the progression of my cloud computing skills.
