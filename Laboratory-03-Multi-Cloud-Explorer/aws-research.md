# AWS Research

## Brief Overview

Amazon Web Services is a cloud platform that provides computing, storage, networking, database, security, and other services through the internet. It allows organizations to use cloud resources without maintaining all of the required physical infrastructure themselves.

## Global Infrastructure

AWS uses a worldwide infrastructure divided into Regions and Availability Zones. Regions represent geographic locations, while Availability Zones provide separate infrastructure within a Region. This design helps applications achieve better availability and reliability.

## Cloud Management Console

The AWS Management Console provides a graphical interface for managing AWS resources. Users can create services, configure settings, monitor resources, and control their cloud environment through a web browser.

## Four Core Services

1. Amazon EC2 – Provides virtual servers for applications and workloads.
2. Amazon S3 – Provides scalable object storage.
3. Amazon RDS – Provides managed relational databases.
4. AWS IAM – Controls users, roles, and permissions.

## Three Advantages

1. Large selection of cloud services.
2. Resources can scale according to demand.
3. Supports organizations ranging from startups to large enterprises.

## Typical Enterprise Use Cases

AWS can support online applications, company websites, database systems, file storage, backup solutions, analytics platforms, and disaster recovery environments.
