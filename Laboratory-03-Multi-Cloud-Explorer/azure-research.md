# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud platform designed to provide computing, storage, networking, databases, security, analytics, and application services. It is widely used by organizations that need cloud infrastructure while working with Microsoft technologies.

## Global Infrastructure

Azure operates across multiple geographic regions and datacenters. Organizations can select appropriate locations for their workloads based on availability, performance, and business requirements.

## Cloud Management Console

The Azure Portal is the main web-based interface for managing Azure resources. It allows users to create virtual machines, configure services, monitor resources, and manage their cloud environment.

## Four Core Services

1. Azure Virtual Machines – Provides virtual computers for cloud workloads.
2. Azure Blob Storage – Stores large amounts of unstructured data.
3. Azure SQL Database – Provides a managed relational database.
4. Microsoft Entra ID – Provides identity and access management.

## Three Advantages

1. Excellent compatibility with Microsoft products.
2. Supports hybrid cloud environments.
3. Provides services suitable for enterprise organizations.

## Typical Enterprise Use Cases

Azure can be used for business applications, Windows-based workloads, databases, virtual desktops, identity management, backup systems, and hybrid cloud deployments.
