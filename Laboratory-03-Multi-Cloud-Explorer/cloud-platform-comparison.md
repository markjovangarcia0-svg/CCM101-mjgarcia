## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

AWS provides one of the largest selections of cloud services. Its services cover infrastructure, storage, databases, networking, security, analytics, and many specialized technologies. This makes it flexible for organizations with different requirements.

### 2. Which provider best integrates with Microsoft technologies?

Azure is the strongest option for Microsoft-based environments. It works closely with technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for artificial intelligence and Kubernetes workloads. Its cloud platform provides services for machine learning, data processing, and managed Kubernetes environments.

### 4. Which cloud platform would you personally choose and why?

I would choose AWS because its large service portfolio provides flexibility for different types of projects. It would allow me to start with basic infrastructure and add additional services as the project becomes more complex.
