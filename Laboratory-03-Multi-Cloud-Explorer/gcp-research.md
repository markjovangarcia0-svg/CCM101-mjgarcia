# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform is a collection of cloud services used for computing, storage, networking, databases, data processing, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud uses regions and zones to organize its infrastructure. Applications can be deployed across appropriate locations to improve availability, performance, and reliability.

## Cloud Management Console

Google Cloud Console is a browser-based management tool. It provides access to cloud resources and allows administrators to configure, monitor, and control their projects.

## Four Core Services

1. Compute Engine – Provides configurable virtual machines.
2. Cloud Storage – Provides scalable object storage.
3. Cloud SQL – Provides managed relational databases.
4. Google Kubernetes Engine – Provides managed Kubernetes clusters.

## Three Advantages

1. Strong tools for data analytics and AI.
2. Good support for containerized applications.
3. Flexible infrastructure for modern cloud workloads.

## Typical Enterprise Use Cases

Google Cloud can be used for data analysis, machine learning, containerized applications, websites, databases, software development, and large-scale computing workloads.
