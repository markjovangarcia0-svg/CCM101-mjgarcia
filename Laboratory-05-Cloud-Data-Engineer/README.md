# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage using MinIO. MinIO is deployed using Docker to provide an S3-compatible object storage server. A bucket is created and a sample file is uploaded using the MinIO Web Console.

## Objectives

- Differentiate Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO.
- Access a cloud service through port forwarding.
- Create a storage bucket.
- Upload an object to the bucket.
- Document cloud storage operations using Markdown.

## Tools Used

- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser

- Using Linux commands
