# Mission Reflection

Object storage is better suited for storing millions of photos because it is designed to handle large amounts of unstructured data. Photos can be stored as objects and organized inside buckets. This makes it useful for applications that need to store many images and other files.

Docker made deploying MinIO easier because the storage server could be started using a single Docker command. Instead of manually installing and configuring many components, Docker provided the environment needed to run MinIO. The port settings and login credentials could also be configured directly in the command.

A bucket is a storage container used to organize objects in object storage. In this activity, the bucket named `client-photos` was created to store the uploaded sample file.

Large enterprise companies can reduce the risk of data loss by keeping multiple copies of their data and using backup and replication systems. If a physical server fails, another copy can be used to recover the stored information.

My confidence in navigating the Linux command line is growing because I am becoming more familiar with commands used to manage files, directories, Docker containers, and Git repositories. Using KillerCoda also gives me a practical environment where I can practice these commands. This activity helped me understand how Linux commands, Docker, and cloud storage can work together.
